BUILT-IN UTILITIES

Biology Tools

Quick calculations and sequence utilities for everyday biology. These are educational convenience tools, not substitutes for validated experimental software or protocols.

ATGC
SEQUENCE UTILITY

DNA Sequence Analyzer

Clean a DNA sequence, count bases, calculate GC/AT content, and generate the reverse complement.

Accepted: A, T, G, C and optional N. Lowercase letters and whitespace are cleaned automatically. One FASTA record at a time.

Supported sequence symbols: A, T, G, C and N. A FASTA header may begin with > on the first non-empty line.

Enter a sequence to see length, nucleotide counts, GC/AT content, and reverse complement.

5′
PRIMER UTILITY

Primer Quick Check

Perform simple length, composition, GC-content, and approximate melting-temperature checks.

Use DNA bases A, T, G and C only. This check does not test specificity or secondary structure.

Use A, T, G and C only. The Tm estimate uses the simple Wallace rule.

Enter a primer to see basic composition and an approximate Tm.

C₁
LAB CALCULATOR

Dilution Calculator

Use C1 × V1 = C2 × V2 to calculate the stock volume and diluent needed for a simple dilution.

C1 and C2 must use the same concentration unit. The calculator does not perform concentration-unit conversion.

Enter C1, C2, and V2 to calculate the required stock and diluent volumes.

SEQUENCE UTILITY

Restriction Site Finder

Search a DNA sequence for recognition sites of a small built-in set of common restriction enzymes.

The tool reports recognition-site start positions, not enzyme cleavage positions.

About BioResource Finder

BioResource Finder combines an educational directory of biological databases with a small set of built-in sequence and laboratory calculation utilities.

Educational project: built-in calculators provide convenience calculations only. For research and laboratory work, verify methods, parameters, database documentation, primer specificity, enzyme conditions, reagent specifications, and protocols using appropriate official scientific resources.
